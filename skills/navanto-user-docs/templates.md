A template is a reusable list of names in order, nothing more: task titles and descriptions, drawing sheet titles, or timeline phase names. Applying one adds that list to a project in one go, so a standard job starts from your standard list instead of being typed in again. Templates live on the **Templates** tab in **Library**, with a filter for **Tasks**, **Drawings** and **Timelines**.

## Applying a template

The quickest place is the **Templates** step when [creating a project](/docs/projects/), which takes one template of each kind. On a live project, use **Apply template** on the **⋮** menu of the page you want to fill — the project's [Tasks](/docs/tasks/), [Drawings](/docs/drawings/) or [Timeline](/docs/timeline/). Anyone who can see that part of the project can apply a template to it; you don't need access to the Templates tab itself.

What the apply screen asks for depends on the kind:

- **Tasks** — lets you set a due date and assignee against each task before it is added. Templates don't carry dates or people of their own, so this is where they get them.
- **Drawings** — a code against each sheet, which you can leave blank. Each arrives as a drawing with no revision yet; add the first revision when you have the sheet.
- **Timelines** — nothing to set. The phases go on the end of the chart in order, each taking the next free colour, ready for you to light up their weeks.

> Applying a template only ever adds; nothing already on the project is touched. That also means applying the same template twice creates the list twice, so check what's already there first.

## Creating and editing templates

The Templates tab is open to anyone whose role includes Library (see [roles and permissions](/docs/roles-and-permissions/)), and administrators are the ones who can change what's on it.

**Add template** starts a new one of whichever kind the filter is showing; give it a name and it exists from that moment. Then **Add task**, **Add drawing** or **Add phase** builds the list one row at a time: each row takes a name, and a task row a description as well. The arrows on a row move it up or down, and drawings and phases arrive on a project in the order you leave them in. Everything saves as you go.

Deleting a row removes just that row; deleting the template removes every row in it with it.
