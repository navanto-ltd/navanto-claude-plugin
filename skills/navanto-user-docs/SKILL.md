# Navanto user documentation

This is the written user guide to the Navanto app. Every page listed below sits next to this file in the same directory; open the one that covers the topic and read it before answering a question about how something is done in Navanto.

Each page says who it is written for. `everyone` applies to anyone signed in, `team` to the construction company's own people, `admin` to screens only administrators can reach, and `clients` to the client portal. Answer in terms of what the person asking can actually see, and say plainly when something is only available to an administrator.

Every page has a public URL you may offer so the user can read the whole thing themselves.
