# Navanto for Claude

Use Navanto, the construction project management platform, from Claude. Ask about your projects, tasks, approvals, site updates, orders, selections and timeline, and have Claude make changes for you.

## What it does

The plugin connects Claude to one remote MCP server, the Navanto API at https://app.navanto.co.uk/api/mcp/plugin. You sign in with your own Navanto account, and Claude can only see and change what your role in Navanto allows.

It also includes Navanto's how-to guides as a skill, so Claude can explain how any part of the app works.

The plugin runs nothing on your computer, and nothing is sent anywhere but Navanto.

## What you need

A Navanto account. Find out more at https://navanto.co.uk.
